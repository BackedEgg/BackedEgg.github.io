Web - Script Context Breakout

문제설명 : 이름을 입력하면 프로필 위젯 화면에 그 이름이 JSON 형태로 표시되는 페이지이다. 목표: 위젯을 그리는 script 블록을 벗어나 코드를 실행시켜라 write up: 문제페이지에 들어…

문제설명 :

이름을 입력하면 프로필 위젯 화면에 그 이름이 JSON 형태로 표시되는 페이지이다.
목표: 위젯을 그리는 script 블록을 벗어나 코드를 실행시켜라


write up:

문제페이지에 들어가면 전광판의 임베디드 코드가 보이고 이름을 넣을 수 있는 입력 란이 보인다. guest 를 입력하면 송출화면 페이지로 넘어가는것을 확인했다.
메인페이지에 이 입력을 처리하는 코드가 보인다.

<input id="name" type="text" name="name" value="guest">


value 란에 저장을 하는것 같았다.

우선

<script>alert(document.cookie)</script>

로 입력해보았지만 이름으로 인식할뿐 공격으로 먹히지 않았다.

그래서 송출화면의 코드도 살펴보았는데

<script>  
  var currentUser = {"name": "guest"};
  document.getElementById("widget").textContent = "안녕하세요, " + currentUser.name + "님";
</script>


라는 코드를 볼 수 있다.

value 값이 그대로 들어간것 같았다.
하지만 따옴표가 있고 기존에 script 가 닫히지 않은 상태 때문에 이걸 script 로 인식하지 않은듯하다
그래서 따옴표와 괄호를 닫아주고 script를 닫은다음에 공격을 진행해보았다. 

"};</script><script>alert(document.cookie)</script>



성공하였다.
