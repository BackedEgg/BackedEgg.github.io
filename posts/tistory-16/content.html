문제설명:

RS256으로 토큰에 서명하는 모임 회원 포털이다. 다른 서비스가 검증에 쓸 수 있도록 공개키도 공개되어있다.

목표: 

공개되어 있는 키를 이용해 토큰 서명을 위조하라.

페이지에 들어가 증명서 발급을 누르면 토큰이 나온다.
하지만 창구 내부 자료는 admin이 아니기에 볼 수 없다.

우선 token을 디코딩해보았다.
헤더

{
  "alg": "RS256",
  "typ": "JWT"
}


페이로드

{
  "username": "student01",
  "role": "member"
}


뒤는 서명
으로 이루어져있다.

가장 먼저 시도해볼 수 있는 공격은 alg를 none으로 바꾸는 공격이다.
하지만 되지 않았다.

페이지를 다시 상세히 보니 

GET  /api/public-key         창구 인영(공개 도장) 열람


라는 문구가 존재했다.

들어가보니 public key 가 존재했다.
이 public key 를 재미나이에게 붙여넣어주니 alg를 hs256으로 바꾸는 공격을 추천해주었고 이를 이용하니 문제가 풀렸다.

이것을 이해하기 위해서는 
우선 rs256이라는 알고리즘에 대해서 알 필요가 있었다.
간단히 설명하자면 rs256은 비대칭 서명 알고리즘이다.


이때 비대칭 방식이란?
토큰을 발급하는 서버는 개인키로 서명하고, 검증하는 서버는 공개키로 서명만 검증한다.
정상적인 알고리즘이라면 공개키는 외부에 유출되어도 토큰을 위조할 수 없으므로 유출이 되어도 상관이없다.

그 다음 hs256에서도 알아야했었는데
이것 또한 간단히 설명하자면 hs256은 대칭 서명 알고리즘이다.
토큰을 생성하는 서버와 이를 검증하는 서버가 똑같은 하나의 비밀 키를 공유한다는 것이다.


따라서,
alg 를 hs256으로 바꾸고 공개키를 활용해 서명을 위조해서 발급 받은 토큰을 서버는 일치한다고 판단해버린것이다.
