Web - Reset Link

문제설명 : 비밀번호를 잊었을 때 이메일로 재설정 링크를 요청할 수 있는 입점 상가 포털이다 (데모 환경이라 실제메일은 발송되지 않고 화면에 링크가 바로 표시된다.) 목표: 메일함에 접근하지 않고 …

문제설명 :

비밀번호를 잊었을 때 이메일로 재설정 링크를 요청할 수 있는 입점 상가 포털이다 (데모 환경이라 실제메일은 발송되지 않고 화면에 링크가 바로 표시된다.)

목표: 

메일함에 접근하지 않고 운영 계정의 비밀번호를 바꿔 로그인하라

Write up:

가입한 이메일 주소에 admin@club.local 로 을 치니 reseturl을 주며 token을 발급받을 수 있다.
우선 해당 url에 들어가볼 수 있는데 들어가면

 

account
: 
"admin@club.local"
howTo
: 
"POST /reset 에 token 과 new_password 를 보내세요."
message
: 
"이 링크로 비밀번호를 변경할 수 있습니다."

 

가 뜬다.
여기서 post의 형태로 기본 url뒤에 reset을 붙여서 토큰과 새로운 패스워드를 보내야한다고 생각했다.

다음과 같은 코드를 작성했고 

fetch('http://127.0.0.1:8117/reset', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({ 
    token: 'YWRtaW5AY2x1Yi5sb2NhbA',
    new_password: '25'
  })
})
.then(response => response.json())
.then(data => console.log('성공:', data))
.catch(error => console.error('에러:', error));

가 떠서 재미나이에게
왜 토큰값은 맞는데 유효하지 않음이 뜨는지를 질문했다.

답변 중  

fetch('http://127.0.0.1:8117/reset', {
  method: 'POST',
  headers: {
    // 형식을 URL-encoded로 변경
    'Content-Type': 'application/x-www-form-urlencoded' 
  },
  // body 형식을 key=value&key=value 형태로 변경
  body: new URLSearchParams({ 
    token: 'YWRtaW5AY2x1Yi5sb2NhbA',
    new_password: '25'
  })
})
.then(response => response.json())
.then(data => console.log('결과:', data))
.catch(error => console.error('에러:', error));



가 정답이었다.

전송데이터 형식이 서버 요구사항과 달랐던 것이다.
나는 response의 헤더를 보고 application/json 형식으로 헤더를 작성해야하는 줄 알았는데 request headers를 봐야했었다.
reqeust header 는 application/x-www-form-urlencoded;charset=UTF-8 이었고 이에 맞춰서 다시 작성하니 풀렸다.
