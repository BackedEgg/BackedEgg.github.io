회고록

최근 제가 공부해 온 과정과 활동들을 돌아보면서, 앞으로 어떤 부분을 보완해야 할지 고민해 보았습니다. 아직 배워야 할 것이 많지만, 그중에서도 특히 중요하다고 느낀 부분은 CTF 경험, AI 활용 능력, 개발 기초 역량, 그리고 최신 보안 이슈에 대한 관심입니다.

1. CTF 경험과 AI 활용 능력의 부족

우선 가장 아쉬운 점은 CTF 참가 경험이 너무 적다는 것입니다. 정보보안을 공부하고 있지만 실제 대회에 참가해 다양한 문제를 접하고, 제한된 시간 안에 문제를 해결하는 경험은 충분히 쌓지 못했습니다.

CTF는 단순히 문제를 많이 푸는 것뿐만 아니라, 모르는 문제를 만났을 때 어떻게 접근하고 해결할 것인지 고민하는 과정 자체가 중요하다고 생각합니다. 그렇기 때문에 앞으로는 실력에 대한 걱정보다 경험을 쌓는 데 집중하며 꾸준히 대회에 참가해야겠다고 느꼈습니다.

특히 AI를 활용하는 능력에 대해서도 많은 고민이 필요할 것 같습니다. 지금까지는 AI를 사용하더라도 원하는 결과를 얻지 못하는 경우가 있었는데, 단순히 AI의 성능이 부족해서라기보다 제가 AI를 효과적으로 활용하는 방법을 충분히 알지 못하기 때문일 수도 있다고 생각합니다.

AI에게 어떤 정보를 제공해야 하는지, 문제를 어떻게 나누어 접근해야 하는지, AI가 제시한 결과를 어떻게 검증하고 개선해야 하는지 등을 더 깊이 공부할 필요가 있습니다.

물론 문제를 이해하기 위한 기초 지식과 개념을 스스로 익히는 것도 중요합니다. 하지만 그와 별개로 AI를 활용해 실제로 우수한 결과를 만들어 내는 경험 역시 중요하다고 생각합니다.

앞으로는 단순히 AI에게 문제의 정답을 요구하는 것이 아니라, AI와 함께 문제를 분석하고 해결하는 방법을 익히고 싶습니다. 특히 AI가 제시한 풀이를 직접 검증하고, 실패한 이유를 분석하며, 더 나은 결과를 얻기 위해 활용 방식을 개선해 나가려고 합니다.

2. 기초 개발 역량의 부족

두 번째로는 개발 공부의 필요성을 크게 느꼈습니다.

현재 파이썬을 어느 정도 사용하고는 있지만, 사실 능숙하게 다룬다고 말하기는 어렵습니다. 간단한 코드를 작성할 때조차 AI에게 의존하는 경우가 많고, 기초적인 알고리즘이나 자료구조에 대한 이해도 부족한 상태입니다.

특히 직접 코드를 작성해 본 경험이 많지 않다는 점이 여러 상황에서 드러나는 것 같습니다. 코드를 읽고 대략적인 동작을 이해하는 것과, 아무것도 없는 상태에서 스스로 코드를 설계하고 구현하는 것은 분명히 다른 능력이라는 것을 느꼈습니다.

그동안 보안 공부에 집중하려고 했지만, 결국 보안 역시 프로그램과 시스템이 어떻게 동작하는지 이해하는 것에서 시작한다고 생각합니다. 프로그램의 정상적인 동작을 충분히 이해하지 못한다면, 그 안에서 발생하는 취약점이나 비정상적인 동작을 정확하게 분석하기도 어려울 것입니다.

따라서 앞으로는 보안 공부와 함께 기초적인 개발 공부도 병행해야겠다고 생각했습니다.

우선 파이썬 문법과 자료구조, 기초 알고리즘부터 다시 공부하고, 작은 프로그램이라도 AI의 도움 없이 직접 구현해 보는 경험을 늘리고 싶습니다. 이후에는 AI를 활용해 작성한 코드와 제가 직접 작성한 코드를 비교하면서 어떤 부분을 개선할 수 있는지도 분석해 보려고 합니다.

AI를 사용하지 않는 것이 목표는 아닙니다. 다만 AI가 만들어 준 코드를 이해하지 못한 채 사용하는 것은 경계해야 한다고 생각합니다.

3. 최신 보안 이슈에 대한 관심과 분석의 부족

세 번째는 최신 보안 이슈를 충분히 깊이 있게 살펴보지 않았다는 점입니다.

보안 관련 뉴스나 사고에 아예 관심이 없었던 것은 아닙니다. 다만 새로운 보안 사고가 발생했다는 사실을 접하는 데 그쳤을 뿐, 왜 이런 사고가 발생했는지, 어떤 취약점이 악용되었는지, 실제 시스템에서는 어떤 문제가 있었는지까지 분석하려는 노력은 부족했습니다.

생각해 보면 정보보안을 공부하면서도 실제로 발생하는 보안 사고를 깊이 있게 살펴보지 않았다는 점이 아쉽습니다.

예를 들어 특정 기업에서 개인정보 유출 사고가 발생했다면, 단순히 개인정보가 유출되었다는 사실을 아는 것에서 끝나지 않고 어떤 경로로 침투가 이루어졌는지, 어떤 보안상의 문제가 있었는지, 이를 방지하려면 어떤 조치가 필요했는지까지 고민해 볼 필요가 있습니다.

가능하다면 공개된 기술 분석 자료나 취약점 정보를 찾아보고, 코드 수준에서는 어떤 결함이 있었는지 이해하는 연습도 해보고 싶습니다.

물론 모든 보안 사고의 구체적인 원인이나 공격 코드가 공개되는 것은 아닙니다. 따라서 확인된 사실과 추측을 구분하면서 자료를 분석하는 태도 역시 중요할 것 같습니다.

앞으로는 최신 보안 뉴스를 꾸준히 확인하는 습관을 만들고, 관심 있는 사건이나 취약점은 조금 더 깊이 분석해 보려고 합니다. 단순히 사건을 아는 사람이 아니라, 사건이 발생한 기술적인 원인을 이해하고 스스로 설명할 수 있는 사람이 되고 싶습니다.

궁극적으로는 새로운 보안 이슈를 접했을 때 어떤 부분을 확인해야 하는지 스스로 판단하고, 관련 기술과 취약점을 연결해 생각할 수 있는 역량을 기르고 싶습니다.

4. 앞으로의 방향

이번 회고를 작성하면서 느낀 것은, 지금 저에게 필요한 것은 새로운 것을 무작정 많이 배우는 것보다 부족한 부분을 정확히 파악하고 꾸준히 채워 나가는 과정이라는 점입니다.

CTF에 꾸준히 참가하면서 실전 경험을 쌓고, AI를 활용해 실제 성과를 만들어 내는 방법을 익히고 싶습니다. 동시에 기초 개발 역량을 보완해 AI가 제시한 결과를 스스로 이해하고 검증할 수 있는 능력도 길러야 합니다.

또한 최신 보안 이슈를 지속적으로 살펴보면서 배운 지식이 실제 보안 사고와 어떻게 연결되는지 고민하는 습관을 만들고 싶습니다.

지금은 부족한 부분이 많다 보니 무엇부터 시작해야 할지 막막하게 느껴질 때도 있습니다. 하지만 처음부터 모든 것을 잘할 수는 없고, 부족한 부분을 알고 있다는 것 자체가 앞으로 무엇을 공부해야 하는지 알려주는 기준이 될 수 있다고 생각합니다.

무엇보다 중요한 것은 이러한 고민을 단순한 다짐으로 끝내지 않는 것입니다.

그동안 무엇을 해야 할지 생각하고 계획하는 데 많은 시간을 사용했다면, 앞으로는 작은 것이라도 직접 실행하고 그 과정에서 얻은 경험을 쌓는 데 더 집중하려고 합니다.

이번 회고가 단순히 부족한 점을 돌아보는 기록에 그치지 않고, 앞으로의 변화를 만들어 가는 출발점이 되었으면 좋겠다고 개인적으로 생각합니다..
