Web - Profile switch

문제 설명: '내 프로필 보기'링크를 누르면 자기소개와 비공개 메모가 담긴 내 프로필을 볼 수 있는 사진관 명부 서비스이다. 목표: 다른 사용자의 프로필을 열람하라 write up: 페이지에 들어가…

문제 설명:

'내 프로필 보기'링크를 누르면 자기소개와 비공개 메모가 담긴 내 프로필을 볼 수 있는 사진관 명부 서비스이다.

목표:

다른 사용자의 프로필을 열람하라

write up:

페이지에 들어가면 우선 로그인이 되어있다.
로그인계정: guest, 회원번호는 2번이 부여되어있다.
밑에 기록조회란에서는 회원번호를 통해 조회를 할 수 있었고,
get/profile?user_id=<번호> 로 자기소개와 개인메모를 json으로 돌려준다는 힌트가 있었다.
기수별 명부 페이지에서 1번번호에 admin 계정이 있는것을 알 수 있었다.
url뒤에 /profile?user_id=1을 넣었더니 flag값이 나왔다.
